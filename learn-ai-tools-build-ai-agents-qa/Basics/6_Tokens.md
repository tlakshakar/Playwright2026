# What Are Tokens in AI?

## 1. Introduction

Tokens are small pieces of text that an AI model uses to understand your prompt and generate a response.

In simple words, when you type something into ChatGPT or Claude, the AI does not process the entire sentence as one unit. It breaks the text into smaller pieces called **Tokens**.

These pieces can be:
- A complete word.
- Part of a word.
- A punctuation mark.
- A combination of spaces and characters.

## 2. Simple Example

Suppose you enter the following prompt:

```text
Test the login functionality of my application.
```

The AI model breaks this text into smaller pieces called tokens.

An illustrative breakdown could look like this:

```text
"Test" | " the" | " login" | " function" | "ality" | " of" | " my" | " application" | "."
```

**Important:** This is only an illustrative example. The actual token breakdown depends on the AI model.

## 3. Tokens vs Words vs Characters

Let's understand the difference:

| Term | Meaning | Example |
|---|---|---|
| Character | An individual letter or symbol | T, e, s, t |
| Word | A complete word | Testing |
| Token | A small piece of text processed by AI | Testing may be one or multiple tokens |

Remember:

**One token does not always equal one word.**

For English text, a rough estimate is:

- 100 tokens ≈ 75 words.
- 1,000 tokens ≈ 750 words.

This is only an approximate conversion. Actual token usage varies depending on the text.

## 4. Why Are Tokens Important in AI?

Tokens are important for the following reasons:

### 1. Input Processing

AI converts your prompt into tokens before processing it.

For example:

```text
Generate test cases for the login page.
```

Your instructions are converted into input tokens.

### 2. Output Generation

AI generates its response using output tokens.

For example:

```text
Test Case 1: Verify successful login.
Test Case 2: Verify login with an invalid password.
```

The generated response consumes output tokens.

### 3. Context Window

Every AI model has a context window limit.

A context window defines how much information the model can process at a time.

For example, if you provide:
- A long prompt.
- Jira defect details.
- Requirements documents.
- Previous conversation history.

All this information consumes tokens.

If the context window limit is reached, the model may not be able to process additional information in the same context.

### 4. Cost of Using AI

Many AI services calculate their API usage charges based on the number of input and output tokens.

Generally:
- More input tokens = More input usage.
- More output tokens = More output usage.

The actual cost depends on the AI model and its pricing.

## 5. Practical Example for a QA Architect

Imagine you are using Claude to analyze Jira defects.

You provide the following prompt:

```text
You are a Senior QA Architect.

Analyze the following Jira defects and identify high-risk areas.

Generate:
1. Defect summary
2. Risk analysis
3. Recommended regression test cases
4. Release risk assessment
```

Now, understand how tokens are used.

**Input Tokens:**

Your prompt + Jira defect information + Additional context.

**Output Tokens:**

The defect summary + Risk analysis + Regression test cases + Release risk assessment generated by AI.

### How Tokens Flow Through AI

```text
Your Prompt + Jira Data
          |
          v
     Input Tokens
          |
          v
       AI Model
          |
          v
     Output Tokens
          |
          v
AI Analysis and Recommendations
```

## 6. How to Reduce Token Usage

As a QA Architect, you can reduce unnecessary token consumption by:

1. Giving clear and specific instructions.
2. Avoiding unnecessary background information.
3. Sharing only relevant Jira defects.
4. Asking AI to generate concise responses.
5. Avoiding repeated instructions in every prompt when the context is already available.

**Example:**

Instead of writing:

```text
Please analyze everything in detail and provide a very long explanation
about all the defects available in the application.
```

Write:

```text
Analyze the provided Jira defects.

Identify:
1. High-risk defects.
2. Business-critical impacted areas.
3. Recommended regression tests.

Keep the response concise and structured.
```

The second prompt is more focused and avoids unnecessary instructions.

## 7. Important Terms to Remember

| Term | Meaning |
|---|---|
| Input Tokens | Tokens sent to the AI model |
| Output Tokens | Tokens generated by the AI model |
| Total Tokens | Input tokens + Output tokens |
| Context Window | Maximum amount of information a model can process in its current context |
| Token Limit | Maximum number of tokens allowed for a particular operation or model configuration |

## 8. Key Takeaways

- Tokens are small pieces of text processed by AI.
- A token can be a complete word or just part of a word.
- Your prompt consumes input tokens.
- AI-generated responses consume output tokens.
- Every AI model has a context window limit.
- Many AI APIs charge based on token consumption.
- Clear and focused prompts help avoid unnecessary token usage.

## 9. Remember This Simple Formula

```text
Input Tokens = Your Prompt + Supplied Context

Output Tokens = AI-Generated Response

Total Tokens = Input Tokens + Output Tokens
```

**In simple words:**

Tokens are the basic units of text that AI reads and generates. The more information you provide and the longer the AI response, the more tokens are generally consumed.
