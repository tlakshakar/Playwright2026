# The journeys and the test data

This has two parts:

- **Six user journeys, step by step**: 
    - register and log in, 
    - browse and filter events, 
    - book an event, 
    - manage bookings, 
    - create events as an admin, and 
    - the cross-user security check. 

    These become the outline for tests.

- **Test data**: the 10 pre-loaded sample events (such as IPL Cricket Finals and AI Summit Hyderabad), plus two test logins.

The test logins in that file include passwords in plain text. They look like shared practice accounts for the training site, but don’t reuse that password anywhere real.
