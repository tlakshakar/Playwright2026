# Where things are on the screen

Automated tests need a precise way to “point at” each button and field.
 
This file lists them page by page: login, events, booking form, admin form, bookings list and booking detail. 

For example, the login button is `#login-btn` and event cards are found by the test ID `event-card`. It stops Claude guessing, which is why the test-writing skill says “never guess selectors".
